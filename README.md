# Tai Sud, nuovo sito (prototipo)

Prototipo multipagina del nuovo sito di Tai Sud: blue box TaiBox, T-Fish, normativa VMS, assistenza, modulistica e contatti.

- Le pagine pronte sono nella cartella principale (`index.html` è la home).
- I sorgenti e lo script che genera le pagine sono in `src/` (`build4.py`).
- Il sito è statico: si pubblica così com'è su GitHub Pages, Netlify o qualsiasi hosting.

Prototipo: il form di contatto non invia dati.
